Safer-RoBIM
整合 BIM 與數位孿生之智慧型自主移動機器人系統

本研究旨在針對現有建築設施管理（FM）階段所面臨的高人力成本、系統韌性不足與能源管理效率瓶頸，開發並驗證一套融合BIM-SLAM、Edge AI與結合多感測器的自主移動機器人（Autonomous Mobile Robot, AMR）之智慧巡檢系統原型，實現高精度空間認知、自主智慧判斷與實務運用整合。

在方法設計上，研究建立一套 ROS 2為技術骨幹的系統架構，以AMR載具、Jetson Orin Nano邊緣運算裝置與多種感測器為載具，依序完成自主巡檢、危險事件偵測，最後於BIM平台整合三個層次的實作流程。系統中同時發展事件級偵測模型與決策機制，將偵測到的風險事件轉為具座標與時間標記的資訊，再疊加於數位孿生模型中，並透過告警郵件等方式推送給維運人員。

研究驗證部分透過PoC小型場域與正式實驗場域的多次腳本化巡檢任務，蒐集事件級資料與偵測結果，運用混淆矩陣與多項評估指標檢視系統效能與不同類別危險徵兆的表現。最終整合量化結果與前端數位孿生成果，說明SAFER-RoBIM在提升建築營運維護階段安全監測效率與風險可視化方面的貢獻，並據此提出後續實場部署與系統擴充的發展方向。

SAFER-RoBIM Architecture 三階段智慧檢測流程

Phase 1 — Perception & Navigation

感測器與馬達整合 : AMR搭載2D LiDAR與RGB-D相機等感測器，結合底盤馬達系統與SLAM演算法，於室內環境中執行自主導航並持續蒐集環境資訊。此階段主要產出為 ROS 2中的定位資訊與感測到的事件狀態，作為後續危險偵測與前端呈現之基礎。

Phase 2 — Object Detection

基於室內危險之物件偵測 : AMR所回傳之影像首先輸入YOLO物件偵測模型進行推論，經由後處理與危險分類模組後，將偵測結果對應至本研究定義之危險腳本等級，並輸出標註好之偵測結果。此階段因此扮演「由感測影像轉譯為語意化危險事件」的角色。

Phase 3 — Frontend Integration & Visualization

Phase 3「前端整合與可視化」 則著重於將 ROS 2 端的資料串接至雲端平台與使用者介面。本研究使用ROS Bridge將 ROS 2座標與事件資料轉為Websocket流，供前端應用程式即時訂閱。前端一方面在APS平台上以BIM模型為背景，顯示AMR 當前位置與偵測事件；另一方面亦透過Foxglove Studio接收即時資料流，進行偵測紀錄對時、標註與危險事件視覺化。當系統判定事件達到特定危險等級時，亦會自動發送警報電子郵件予維運人員，以支援後續之應變與決策。

危險事件分級矩陣
不僅是偵測，更是智慧的決策

Q1 重要且緊急——事故等級事件

定義： 涉及人身安全與火警之重大事故。
行動： 即時通報保全與職安單位。

Q2 重要但不緊急——日常異常與缺失

定義： 結構缺失、環境積水等潛在合規風險。
行動： 排程發送郵件，列入維修工單。.

Q3 不重要但緊急——可自行處理之近失事件

定義： 暫時性障礙物，可快速排除之事件。
行動： 現場人員處理，記錄行為供後續改善。

Q4 不重要且不緊急——正常監測情境

定義： 環境狀態符合標準。
行動： 轉為巡檢紀錄，供模型訓練使用。

Communication Pipeline ROS 2 資料流與雲端整合架構

  • Input: LiDAR / IMU / RGB-D → ROS 2 topics
  • Core: SLAM + YOLO inference on Jetson Orin Nano
  • Control: /cmd_vel → motor controller, feedback to ROS 2
  • Monitoring: ROS Bridge → WebSocket → Remote PC/Web dashboard
  • 本架構以 Jetson Orin Nano 為 ROS 2 核心，整合感測、導航、YOLO 推論與遠端監看，透過 ROS Bridge 將事件與狀態串流到 Web 端。

實驗場域與巡檢路徑規劃

PoC小型場域測試

本研究第一階段於單室開放式研究室進行測試。空間採開放配置，中央為會議長桌，北側設置沙發區，東側為連續工作桌與儲櫃。通道寬度不一且邊界模糊，適合作為路徑規劃與避障驗證場域。測試期間維持固定人工照明，以確保偵測效能評估的一致性。

正式場域測試：室內工廠環境

本場域具備低人流、非連續作業特性，環境包含膠合木箱作業區、龍門吊架與木製夾具。地坪以黃黑警示線劃分走道，並佈置交通錐與碎磚作為導航避障之臨時障礙物，為機器人感測與測試提供理想的驗證空間。
