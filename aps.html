校園碳足跡視覺化決策平台

Autodesk Platform Services（APS）為 Autodesk 提供之雲端 API 平台，支援開發者在網頁環境中整合 BIM 與工程資料。本專案建構一套數位孿生儀表系統，整合 BIM 模型、即時 IoT 資料與系統級分析功能。系統採用 APS Viewer 進行三維視覺化，透過 OAuth 驗證機制確保資料安全，並開發自訂 UI Extension 以呈現動態能源與 ESG 指標，將靜態建築模型轉化為可運作之決策支援平台。

本計劃以建築系館為示範場域，目標建立一套整合「靜態建築碳排」與「動態人流活動碳排」的校園碳排分析平臺。透過跨領域合作，整合BIM建模、影像辨識人流感知、機器學習預測模型與碳排計算機制，最終於APS平台上建構碳排視覺話與熱點分析系統。

本專案中，我負責 APS（Autodesk Platform Services）數位孿生平台之開發與整合，將建築碳排數據與人流活動碳排數據串接至雲端 API，建構三維碳排視覺化介面。平台實作內容包含：

  • 建立 APS Viewer 與 BIM 模型整合架構
  • 設計資料格式轉換機制，使靜態與動態碳排數據可映射至模型元素
  • 開發熱力圖與建築元素著色邏輯
  • 建構前端資料互動與查詢功能
  • 串接後端資料庫以實現即時更新

Data Sources

建築與碳排模型
  • BIM 模型：整合樓層/房間/構件及靜態碳排屬性（Embodied / Operational）。
  • Carbon Model：結合靜態能耗與動態人流，計算時空標記排放量。
感知與預測流水線
  • CV Pipeline：多攝影機偵測與追蹤去重，產出人流計數與時序資料。
  • ML Pipeline：基於時間序列預測活動類型、未來趨勢與情境分析。

Backend Integration Layer

數據規範與映射
  • 建立統一資料Schema：定義時間戳、空間 ID、排放量、類別及信心值。
  • Mapping 機制：建立空間 ID 與 BIM 構件（db_key/element_id）的映射表。
資料交換架構
  • RESTful API（目標）：依碳排/減碳量尺度自動渲染構件顏色。
  • 即時通訊機制（目標）：整合 WebSocket 或長輪詢實現數據即時更新。

APS Visualization

平台核心整合
  • BIM 整合：基於 SVF2 格式載入，實現精確三維瀏覽。
  • 資料映射：透過 dbId / externalId 將碳排數據精準 join 至模型構件。
雙重視覺化模式
  • 構件著色 (Coloring)：依碳排/減碳量尺度自動渲染構件顏色。
  • 動態熱點 (Heatmap)：人流與活動碳排時空分布圖，支援多維度切換。

APS 數位孿生DEMO

Multimodal Data Sensing

邊緣感知與能源監測
  • CCTV Real-time Stream：整合場域監控影像，提供各空間即時影像串流 (Streaming) 以供狀態比對。
  • Smart Metering：接入智慧電表數據，獲取電力能耗、電壓與瞬時功率，作為動態碳排計算之基底。
  • 人流定位：結合 CV 與定位技術，輸出人員空間座標與活動強度資料。

Backend & Data Hub

數據規範與映射機制
  • 統一 Schema 設計：標準化時間戳、空間 ID、能耗數據與人流信心值之資料封裝。
  • APS 雙向映射：建立電表/攝影機與 BIM 構件（ExternalId）的關聯表，確保數據精準映射至 3D 元素。
  • 即時通訊層：透過 WebSocket 同步回傳分析數據，驅動模型實現毫秒級狀態反應。

APS UI/UX Extensions

智慧延伸模組開發
  • Custom Docking Panels：參考 Autodesk APS Extensions，開發自定義面板以承載 CCTV 串流視窗與能耗圖表。
  • 熱力圖與狀態渲染：基於即時數據驅動 Shader，在模型表面渲染動態熱力圖與構件著色 (Theming Color)。
  • 智慧聯動機制：點擊 BIM 構件可立即調用該空間之實時影像與電力曲線，實現資訊與模型的深度耦合。
